1. 获取配置  
首先设备开机联网后会调用获取配置接口，帽子本地内置了一个获取配置接口的 url ，默认获取配置地址是
在设备去调用这个接口时会在 url 后面拼接当前设备号和版本信息
拼接结果：
这个接口返回响应参数中会包括一个 http 请求地址（参数名为 api_url, 获取后设备发送 http 请求会基于这个
地址发送，例如文件上传等操作）和长连接地址（ websocket 地址，参数名为 ws_url ，获取后设备登录、上
报实时定位等数据和接受服务端指令报文，都是基于这个地址去发送和接收）
关于设备上报地址的更改方案：
方案一 ：让设备在我们 caps 平台获取数据上报地址，如上所说帽子内置了从我们后台获取配置接口的地址，
开机时便会去调用，也就是说获取配置接口返回用于设备上传数据两个地址，可以用设备对应的管理员账号
登录我们指挥调度平台，在开关设置里更改对应参（ HTTP 请求地址和长连接地址）。
这个方法在高端和低端型号帽子上都可用，流程是： 设备开机 → 从公网在我们平台调用接口获取配置 → 接口
响应返回数据上传地址
 
方案二 ：修改帽子获取配置地址，对于高端型号设备（可以理解为带有摄像头的帽子）来说，有方法可以修
改内置的获取配置地址，可达到指定设备往目标平台调用接口获取配置的效果。
修改方法一、修改方法二，这两个方法仅对高端设备有效，低端型号设备建议用方案一，或者定制版本刷机
修改内置获取配置地址。
 
采用方案二需求后台实现获取配置的接口，接口说明：
实现这个接口时避免出差错，建议 url 里的路径名和路径要求格式中保持一致 ( 即使不是使用 php 后端开发 ) ，
查询字符串参数和响应返回参数格式也保持一致，返回参数可跟参数示例保持一致，主要更改 api_url 和
ws_url 两个参数即可。
请求路径要求格式： http:// [ 目标服务器 ip:port 或  域名 ]/api/index.php?ctl=config&act=get_config
请求协议： HTTP 、请求方式： GET
接口返回参数示例： https://mg.runde.pro/api/index.php?ctl=config&act=get_config
