## 环境问题记录（html-to-docx 转换）
- `setup-html-to-docx.sh` 在本机 Windows/Git Bash 下不可直接用：
  1. 脚本 `rm -rf $VENV_DIR`（目录不存在时）触发 safe-delete 包装器 fail-closed，直接退出。
  2. 脚本按 `$VENV_DIR/bin/python` 探测就绪，Windows venv 是 `Scripts/python.exe`，永远误判需重建。
  3. `uv venv "$HOME/.venv-html-to-docx"` 的 POSIX 路径被错误转换到 `E:\c\Users\...`。
- 可用绕法：`cd C:/Users/6484 && uv venv --python 3.12 .venv-html-to-docx`（相对路径避开转换），然后 `uv pip install --python .venv-html-to-docx/Scripts/python.exe --only-binary=:all: -r <skill>/scripts/requirements.txt`，再 `cd <skill>/scripts && python.exe -m html_to_docx convert ...`。
